# Modeling
# Known-good trio (validated in the predecessor repo's working venv, and required to be
# mutually compatible): transformers 5.x <-> transformer_lens 3.3 (both use the new
# `dtype=` from_pretrained kwarg) <-> torch >= 2.7 (provides torch.float8_e8m0fnu that
# transformers 5.x imports). Do NOT mix transformers 4.x with transformer_lens 3.3.
#
# POD/torch: install torch SEPARATELY from a CUDA wheel matching the driver -- do NOT let
# a blanket `pip install` pull the default-PyPI torch (it can need a newer driver than the
# pod has -> "NVIDIA driver too old" -> silent CPU fallback, or an ABI-mismatched
# torchvision -> "torchvision::nms does not exist" masquerading as a BERT import error).
# Pick the cuXXX <= the driver's CUDA (see `nvidia-smi`), e.g. for a 12.8 driver:
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
# We do NOT use torchvision; if it is present-but-broken: `pip uninstall -y torchvision`.
# See docs/PIPELINE.md "Troubleshooting".
