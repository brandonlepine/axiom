\section{Proposed Study Architecture}

\subsection{Separate Identity Representation from Stereotype Expression}
We already have: 
\begin{itemize}
    \item Identity-only dataset
    \item WinoQueer: identity plus stereotype continuation
    \item BBQ / CrowS - WinoGender and WinoRace
\end{itemize}

Use these to estimate three things: 
\begin{enumerate}
    \item $v_{identity}$ - from identity-only contrasts
    \item $v_{bias}$ - from biased minimal pairs
    \item $v_{stereotype} = v_{bias} - v_{identity}$ as a rough residualization stereotype-association direction
    \item $v_{stereotype}'$ - derive from a stereotype only dataset 
\end{enumerate}

Then ask: 
\begin{enumerate}
    \item Does $v_{identity}$ steer demographic recognition without increasing stereotypes?
    \item Does $v_{bias}$ steer stereotype continuations
    \item Does subtracting $v_{identity}$ preserve stereotype steering or destroy it. 
\end{enumerate}

\subsection{Treat the Datasets as Matched Bias Axes}
For each dataset, run the same battery: 
\begin{itemize}
    \item residual patching
    \item head patching
    \item head ablation 
    \item greedy knockout
    \item steering 
    \item MLP attribution
\end{itemize}
